## Challenges Faced & Lessons Learned

### Challenges Faced
* **Linking Forms to Input Elements:** Ensuring all `<input>`, `<textarea>`, and `<select>` elements in `contact.html` were correctly tied to their `<label>` elements using explicit `for` and `id` pairs to ensure accessibility compliance[span_0](start_span)[span_0](end_span).
* **Maintaining Relative Path Consistency:** Managing multi-page link references across `index.html`, `about.html`, `projects.html`, and `contact.html` so that visitors can navigate smoothly without broken paths[span_1](start_span)[span_1](end_span).
* **Converting Block Layouts to Semantic HTML:** Transitioning from relying heavily on general `<div>` tags to adopting semantic elements like `<main>`, `<article>`, `<aside>`, `<header>`, and `<footer>` for better document hierarchy[span_2](start_span)[span_2](end_span).
* **File Naming Standards for Deployment:** Ensuring strict lowercase naming for all files (such as `semantic-conversion.html`) to prevent case-sensitivity routing issues once published on GitHub Pages[span_3](start_span)[span_3](end_span).

### Lessons Learned
* Discovered how to run Lighthouse performance and accessibility audits within browser DevTools.
* Gained hands-on experience using Git version control and writing clear commit messages throughout the development process.
* Learned how proper HTML semantics significantly improve both search engine visibility and screen reader accessibility.
