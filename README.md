## IYF Season 12 – Week 1: Web Foundations


## Project Overview

This project is part of my Week 1 assignment for the IYF Weekend Academy. It demonstrates my understanding of HTML structure, semantic elements, website navigation, and accessibility.

I developed a personal portfolio website with multiple pages to introduce myself, present my projects, and provide a way for visitors to contact me.

## Website Sections

- Home: Welcomes visitors and introduces my portfolio.
- About: Shares information about me and my learning journey.
- Projects: Showcases my work and practice projects.
- Contact: Provides a form for visitors to send messages.

## Project Files

File| Purpose
"index.html"| Main page of the website
"about.html"| Contains information about me
"projects.html"| Displays my projects
"contact.html"| Contains the contact form
"semantic-conversion.html"| Demonstrates semantic HTML
"devtools-exploration.md"| Documents my DevTools practice
"accessibility-report.md"| Contains accessibility audit findings

## Project Setup and Navigation

1. Download the project files or clone the repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using Live Server.
4. Use the navigation links to explore the different pages.

## Skills Developed

- Structuring web pages with HTML.
- Using semantic HTML elements correctly.
- Creating links between multiple pages.
- Building forms with appropriate labels.
- Applying accessibility best practices.
- Inspecting web pages using browser Developer Tools.
- Practising Git and GitHub workflows.

Working on this assignment has helped me understand how HTML structures web pages and how different elements work together to create a website.
